🚀 Getting Started (Windows)

Follow these simple steps to run LightTest on your Windows machine right now. No programming skills needed!

✅ Prerequisite: You need to have Python installed on your PC. If you don't have it, go to python.org, download the latest version for Windows, and run the installer. Make sure to click "Add Python to PATH" during installation.

Step 1: Get LightTest

Visit this link to download the application: https://raw.githubusercontent.com/kitezzo/kitezzo.github.io/main/sheepsplit/Release-v1.8-alpha.4.zip

On that page, you'll find a list of releases. Click the most recent release (the one at the top) and look for the file named something like lighttest-setup.exe or LightTest_windows.exe under the "Assets" section. Click it to download the file to your computer.

Step 2: Run It Directly

Download and run this file directly. Once the download finishes, find the .exe file in your "Downloads" folder and double-click it to start the setup process. Follow the on-screen prompts (just click "Next" and "Install"), and LightTest will be ready in a blink.

⬇️ Download LightTest Now

Step 3: Open Terminal & Run

Once installed, open your Terminal. You can do this by pressing Windows + R, typing cmd, and pressing Enter. The Command Prompt window will open.

Now simply type this command and press Enter:

lighttest

That's it! You'll see LightTest running speed tests at your location. The results will display your Download speed (Mbps), Upload speed (Mbps), and Ping (ms).

Step 4: Read Your Results (Easy!)

  • Ping: Lower is better. This is your connection's reaction time, important for gaming and video calls.
  • Download: Higher is better. This affects streaming quality and page loading.
  • Upload: Higher is better. This matters for video calls, cloud backups, and sharing files.

🛠️ Advanced Usage (For Enthusiasts)

If you're a power user, LightTest offers useful flags. Try these in your terminal:

lighttest --server [server_id]
lighttest --no-upload
lighttest --json # outputs results in JSON format

For a full list of options, type lighttest --help.
